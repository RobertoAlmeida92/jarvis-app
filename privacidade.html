Política de Privacidade do JARVIS

O JARVIS é um assistente pessoal de uso privado. Só o dono da conta Google que o autorizou o utiliza.

Dados acessados

Com a autorização do dono, o JARVIS acessa os dados dessa conta Google: e-mails (leitura e envio confirmado pelo dono), agenda, contatos e tarefas.

Uso dos dados

Os dados são usados apenas para responder aos pedidos do próprio dono, como consultar a agenda ou criar uma lista de tarefas. Eles não são vendidos, não são compartilhados com terceiros para publicidade e não são usados para treinar modelos de IA.

Armazenamento

O acesso é autorizado por um token guardado no servidor doméstico do dono. Para responder aos pedidos, trechos dos dados podem ser processados pelo serviço de IA usado pelo assistente.

Revogação

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
